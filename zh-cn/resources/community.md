# 社区

## 技术委员会

快递技术委员会每两周举行一次网上会议（视需要），讨论快递的开发和维护问题。
和其他与快递项目相关的问题。 每次会议通常在
中宣布[表达/讨论问题](https://github.com/expressjs/discussions/issues)，并有一个链接来加入或查看会议。 它是
向所有观察员开放。

会议已被录制；记录列表见[Express.js YouTube频道](https://www.youtube.com/channel/UCYjxjAeH6TRik9Iwy5nXw7g)。

## 许多模块都是快递的

我们充满活力的社区已创建了大量各种各样的扩展、[中间件模块](/{{ page.lang }}/resources/middleware.html)和更高层次的框架。请在 [wiki](https://github.com/expressjs/express/wiki) 中了解详细信息。

此外，Express 社群在这两个GitHub orgs中保留模块：

- [jshttp](https://jshttp.github.io/) modules providing useful utility functions; see [Utility modules](/{{ page.lang }}/resources/utils.html).
- [pillarjs](https://pillarjs.github.io/)：表示内部使用的低级模块。

要跟上整个社区正在发生的事情，请查看 [ExpressJS StatusBoard] (https://expressjs.github.io/statusboard/)。

## 议 题

如果您发现程序中存在错误，或者只是希望提出功能请求，请在[问题队列](https://github.com/expressjs/express/issues)中开具凭证。

## 示例：

在资源库中查看数十个快速应用程序 [examples](https://github.com/expressjs/express/tree/master/examples)
涵盖从API 设计和身份验证到模板引擎集成等所有方面。

## Github Discussions

[GitHub Discussions](https://github.com/expressjs/discussions)部分是参与开发和维护快车道的对话的绝佳空间。 并交流想法和讨论与其使用有关的议题。
