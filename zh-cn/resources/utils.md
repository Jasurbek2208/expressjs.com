## 快递实用功能

[pillarjs](https://github.com/pillarjs) GitHub 组织包含了一些可能一般有用的实用功能模块

| 实用模块                                                           | 描述                                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [cookies](https://www.npmjs.com/package/cookies)               | 获取并设置 HTTP(S) cookie 可以签名来防止篡改，使用Keygrip 可以与 Node.js HTTP 库或快递中间件使用。                                                                                                                                                                  |
| [csrf](https://www.npmjs.com/package/csrf)                     | 包含CSRF 令牌创建和验证背后的逻辑。  使用此模块创建自定义 CSRF 中间件。                                                                                                                                                                                                                               |
| [finalhandler](https://www.npmjs.com/package/finalhandler)     | 作为响应HTTP请求的最后一步的函数。                                                                                                                                                                                                                                                      |
| [parseurl](https://www.npmjs.com/package/parseurl)             | 解析缓存的 URL。                                                                                                                                                                                                                                                               |
| [path-match](https://www.npmjs.com/package/path-match)         | 环绕 [path-to-regexp](https://github.com/component/path-to-regexp)的薄包装，使提取参数名称更加容易。                                                                                                                                                                                        |
| [path-to-regexp](https://www.npmjs.com/package/path-to-regexp) | 将 \`\`/user/:name\` 等快速模式路径字符串转换为正则表达式。                                                                                                                                                                                                                  |
| [resolve-path](https://www.npmjs.com/package/resolve-path)     | 针对带验证的根路径解析相对路径。                                                                                                                                                                                                                                                         |
| [router](https://www.npmjs.com/package/router)                 | 简单的中间路由器。                                                                                                                                                                                                                                                                |
| [routington](https://www.npmjs.com/package/routington)         | 用于定义和匹配URL的三重网址路由器。                                                                                                                                                                                                                                                      |
| [send](https://www.npmjs.com/package/send)                     | 传输文件作为HTTP响应的库，支持部分响应 (范围)、条件-GET谈判和颗粒事件。                                                                                                                                                                                                             |
| [templation](https://www.npmjs.com/package/templation)         | 查看由 [co-views](https://github.com/visionmedia/co-views和 [consolidate.js](https://github.com/visionmedia/consolidate.js/)启发的 `res.render()` 相似的系统。 |

更多低级别 HTTP 相关模块，见 [jshttp](http://jshttp.github.io/)。
